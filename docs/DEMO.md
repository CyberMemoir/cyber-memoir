# 可运行的本地演示

这不是业务部署。演示运行真实 Web/API、审核、检索与证据存储代码；使用独立临时 SQLite 和本地对象目录。所有初始条目、日期、平台 URL 和摘录均为**合成软件夹具，不是真实互联网文化资料**。平台 URL 仅作占位，未抓取对应作品。

## 一条命令启动

需要 Python 3.12–3.14、uv、Node.js 22 和 npm；不需要 Docker、业务 `.env`、平台账号或模型权重。

```bash
cd apps/backend && uv sync --frozen && cd ../..
cd apps/web && npm ci && cd ../..
make demo
```

看到“本地演示已就绪”后打开 <http://127.0.0.1:3102>。这是 Next 开发服务器，首次进入路由会编译；`make check` 另行验证生产构建。

- 审核工作台：<http://127.0.0.1:3102/review>
- 演示专用令牌：`local-synthetic-demo-only`，不是部署凭据。
- API 健康检查：<http://127.0.0.1:8102/health/ready>
- `Ctrl+C` 同时停止两端、清理临时数据库/对象，下一次重新初始化。
- 两端仅绑定 `127.0.0.1`；端口占用时退出，不停止已有服务。修改端口：

```bash
cd apps/backend
uv run --project . python ../../ops/demo.py --web-port 3103 --api-port 8103
```

Web 使用独立的 `.next-demo` 构建目录；不要将这个实例作为业务环境或长期数据源。

## 五分钟走一遍

1. 首页检索 **合成星灯**：查看真实检索结果与独立回答状态。没有模型时使用数据库/词法回退和抽取式回答，页面保留降级信息，不声称模型召回效果。
2. 打开「合成演示：星灯亮起」：点击定义/用法的编号引用，查看原文、证据定位、记录和附件 SHA，返回引用位置。复制带 `expected_revision` 的分享链接。
3. 查看「合成演示：星灯续章」：演示条目关系、月份精度和小红书来源标签；起源仍为未知，不能把首次使用当起源。
4. 进入审核工作台，输入演示令牌。初始队列有一条「合成演示：等待审核」。修改定义后必须重新选定支持完整字段的证据，明确核对，再提交审核决定。
5. 审核通过后从公开检索进入该条目。在工作台执行撤回，重新搜索/打开详情，观察公开证据资格变化。所有变化只在临时演示库里发生。
6. 提交页可使用唯一允许的合成链接：`https://www.bilibili.com/video/BV1DEMO00002`。本地 Worker 生成明确标注的合成元数据和待人工编辑的稿件；审核队列会自动刷新。也可以在该来源下补充带定位说明的文本材料。

跨平台文件导入也调用真实的预演/待审接口，文件格式见 [导入指南](PUBLICATION_IMPORT.md)；演示里只使用自行编写的合成包。关闭实例时导入内容一并清理。

## 演示边界与复现

- 后端关闭 `.env` 加载，覆盖数据库/存储/身份配置，清空模型 API、平台 cookies 和 S3 凭据。
- Redis、OpenSearch 和模型均关闭；本地 Worker 使用持久任务表的轮询回退。平台元数据函数替换为固定合成材料，不向上游平台发请求。
- 提交接口拒绝其他链接（含短链接），媒体上传拒绝运行 ASR/OCR；人工文本材料、导入、审核、撤回仍使用实际应用服务。
- 初始化仅为**临时合成库**创建表并模拟发布两条夹具，另留一条待审。业务发布仍必须人工审核；演示不是 PostgreSQL 迁移、并发事务或模型准确率的验收。
- 自动化验收：`tests/test_demo_server.py` 启动独立子进程，核对合成条目、配置隔离、公开引用、审核闭环、上游拒绝和 Worker；浏览器验收还应在实际演示上点击并检查桌面/手机。

在全新演示实例上运行真实浏览器验收（会批准/撤回合成待审稿，结束后重启演示恢复初始队列）：

```bash
cd apps/web && npx playwright install chromium && cd ../..
node ops/demo_smoke.mjs
# 可选：CYBER_MEMOIR_DEMO_URL=http://127.0.0.1:3103 node ops/demo_smoke.mjs
```

脚本核对后端合成演示标识才开始写入，不拦截 API、不模拟响应、不替换浏览器时钟。
