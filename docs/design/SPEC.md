# 界面设计规格

参考：`archive-concept.png`，内置 Image Gen 生成的完整主屏幕概念，原生 1505 × 1045。

- 主题：数字图书馆，白色背景 `#fff`，深墨文字 `#202622`，档案绿 `#185e43`，浅绿侧栏 `#f3f8f5`。
- 构图：顶栏、双行衬线标题、检索栏、平台页签、2.2:1 内容/原则侧栏、页脚。
- 字体：中文标题系统宋体，界面 `system-ui / PingFang SC`；正文 16px，标题桌面 60px、移动端 34px。
- 间距：桌面 50px 页边距；顶栏 90px；检索控件 54px；细边框、4px 圆角，无渐变。
- 组件：导航、按钮、搜索框、平台页签、档案列表、空态、原则侧栏、抽屉/表单、证据引用、事件时间线。
- 图标：原生 SVG 细线图标（搜索、箭头、档案、信息），不使用截图充当 UI。
- 首屏文案：Cyber Memoir、赛博回忆录、记忆索引、提交来源、审核工作台、GitHub、记住一个梗，也记住它从哪里来。、梗、语境与传播轨迹。每一个解释，都有证据可循。、搜索梗、别名、创作者或一句话…、搜索记忆、全部平台、Bilibili、抖音、基于证据回答。
- 下游页面按同一规格实现：提交来源、材料补充/任务进度、审核工作台、梗详情/证据/时间线、搜索和回答状态。
- 必需偏差：结果数量来自真实数据库；异常显示真实错误；首次部署为空库，不创建文化事实示例。
- 响应式：小屏侧栏降为下方区域，导航允许换行，搜索按钮保持可操作，表单和证据不溢出。

生成提示摘要：完整中文证据型梗档案应用主屏、真实空态、白底绿色数字图书馆、原生文本控件、禁止虚构统计和文化事实。
