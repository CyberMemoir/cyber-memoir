生成概念：`semantic-review-desktop.png`（1505×1045）和 `semantic-review-mobile.png`（952×1654）。概念覆盖导入、队列选择、评级表单、原文/摘录、导出；样例全为软件合成，不是真实判断。

- 延用 `DESIGN.md` 黑色夜空、灰线和薄荷交互、原品牌/四项导航/图标。桌面三列：断言轨道、表单、保存证据；≤1100px按同一顺序纵向排列；390px控制明确换行，不缩成三窄列。
- 标题38px（手机32px），正文字段16px，辅助标签14px、反馈13px；四像素边角与细边框。生成手机图是放大的阅读概念，实际CSS坚持既有可读字号，不把图片像素直接当CSS像素。952×1654原生纵向视口及390×844均检查。
- 已确定的复制文本：标题“本地语义复核”；说明“文件仅在本机浏览器处理，不自动上传或发布。”；导入/加载/导出三控件；断言队列、只读断言、主张类型、复核结论、复核者、必填理由、选中摘录、保存/撤回本地评级、保存证据/添加摘录。每个计数取实际文件，未导入为0，不自动填演示或预选支持。
- 设计生成中错误的可选理由已在桌面概念修正为必填。保留原网站准确的SVG品牌与头部布局，不重画生成图中的近似螺旋。手机图初版的设备框/状态栏/汉堡已拒绝，最终概念只保留页面内容。真实合成演示额外的固定demo说明条不是工作台视觉结构，普通页面比较不含它。
- 新的空状态、校验失败、保存/撤回/导出反馈，以及稿件丢弃确认，是功能必要状态，采用已有notice/error处理；不新增未被设计的营销段、装饰badge、文化发布或自动模型操作。
- 证据只用单一文字节点pre显示，保留真实文字与换行。没有为了视觉的行号/markup污染选区。鼠标/键盘选区UTF-16转Unicode码点，保存范围和literal exact/hash；没有默认摘录或生成解释。
- 无自动上传、网络模型、业务API或浏览器磁盘持久化；文件在本页内存，保存后仍须主动导出。任何复核身份/保存时间都是声明归属/本机时钟，不认证真实人或文化发布。丢弃稿件需明确选择。
